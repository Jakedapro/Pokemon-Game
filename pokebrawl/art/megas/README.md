# Mega Evolution sprites

PokeBrawl's own Mega Evolutions (Mega Flygon, Luxray, Arcanine, Milotic, Typhlosion, Snorlax, Lapras,
Ninetales, Machamp and Togekiss) switch on automatically once their sprite is here.

- One front sprite per Pokemon, named after the base Pokemon: `flygon.png`, `luxray.png`, `arcanine.png`,
  `milotic.png`, `typhlosion.png`, `snorlax.png`, `lapras.png`, `ninetales.png`, `machamp.png`, `togekiss.png`.
- Transparent background, GBA style, 64x64 (or 80x80). It's shown at 2x in battle.
- Types, stats and abilities are in `pokebrawl/riftdex.py` (`CUSTOM_MEGAS`).
