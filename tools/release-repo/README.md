# PokeBrawl

A Pokémon battle and adventure fan game for Mac and Windows: a full FireRed-style story, Mega Evolutions, ranked
1v1s against your friends, online rooms, showcases and more.

## Download

Get the newest version from **[Releases](../../releases/latest)**:

| Computer | File |
|---|---|
| Mac with Apple Silicon (M1/M2/M3/M4...) | `PokeBrawl-mac-arm64.zip` |
| Mac with Intel | `PokeBrawl-mac-intel.zip` |
| Windows 10 / 11 | `PokeBrawl-windows-setup.exe` |

Not sure which Mac you have? Apple menu → About This Mac: "Chip: Apple M..." means Apple Silicon.

### Easiest: one command

**Mac** - open Terminal and paste:

```bash
curl -fsSL https://raw.githubusercontent.com/Jakedapro/PokeBrawl/HEAD/install.sh | bash
```

**Windows** - open PowerShell and paste:

```powershell
irm https://raw.githubusercontent.com/Jakedapro/PokeBrawl/HEAD/install.ps1 | iex
```

These download the right version, put PokeBrawl in your Applications / Start menu and skip the "unknown developer"
warnings.

### Or download it yourself

- **Mac:** unzip, drag **PokeBrawl** into Applications. The first time, right-click it → **Open** → **Open**
  (on newer macOS: System Settings → Privacy & Security → **Open Anyway**).
- **Windows:** run the setup. If a blue "Windows protected your PC" box appears: **More info** → **Run anyway**.

The game updates itself after that. Your save is kept in `~/.pokebrawl` and survives updates.
